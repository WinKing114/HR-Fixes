# HR Fixes

**Targeted compatibility and bug fixes for Hollow Realm**

HR Fixes is a lightweight Minecraft Forge mod developed specifically for the **Hollow Realm** modpack.

It focuses on resolving reproducible mod conflicts, crashes, and gameplay issues through targeted Java and Mixin patches.

Each fix aims to be minimal, reliable, and limited to the intended mod configurations while preserving existing gameplay.

## Project Information

- **Minecraft:** 1.20.1
- **Mod Loader:** Forge
- **Mod ID:** `hollowrealm_performance_compat`
- **Java Bytecode Target:** Java 17

## Development Approach

HR Fixes follows an evidence-based maintenance approach: identify real problems, confirm their causes, apply narrowly scoped fixes, and verify the affected behavior.

The project complements configuration files, KubeJS, and data packs rather than replacing them. Optional compatibility patches are intended for their documented, audited mod versions; support for all combinations is not guaranteed.

## Builds and Compatibility

Use only builds published or explicitly provided by the maintainer. Development candidates are not automatically public releases.

Compatibility claims apply only to the documented test environments. Full Hollow Realm dedicated-server and long-term gameplay compatibility should not be assumed.

See the [Releases](https://github.com/WinKing114/HR-Fixes/releases) page for available public releases and their release notes.

Historical candidate verification and limitations are preserved in the [October 24, 2026 README snapshot](docs/archive/README-2026-10-24-1.1.3-rc.1.md).
