HollowRealm Fixes (formerly HR Fixes) is a lightweight code-level compatibility and bug-fix mod built for the HollowRealm modpack on Minecraft 1.20.1 (Forge). It resolves confirmed crashes, concurrency races, and broken UI/JEI integrations using version- and bytecode-gated Java/Mixin patches without altering gameplay balance, recipes, quests, or progression.

Install this mod if you play HollowRealm (or run the same audited mod versions) and want silent, fail-closed fixes for vanilla and cross-mod issues. Data-pack and recipe/loot condition fixes live separately in HollowRealm Tweaks.

⚙️ What's Included

Every patch runs through HRFixesMixinPlugin (or a guarded Forge CoreMod) and fails closed: if a target mod is absent, updated to an unaudited version, or has unexpected bytecode, that patch skips cleanly without crashing startup.

  • Vanilla Chat Line-Height Crash Guard: Prevents divide-by-zero crashes in ChatComponent when chat line spacing produces an integer line height below 1 or non-finite values (NaN / ±Infinity), falling back safely to 0.0 while keeping all valid spacing values intact.
  • L2 Hostility × KubeJS Cache Race Fix: Synchronizes LHKJSPlugin.clearCaches() under AttackEventHandler's registration lock to eliminate concurrent modification risks during reloads and combat listener setup.
  • Lodestone × AttributesLib Tooltip Race Fix: Marks the audited AttributesLibClient base-modifier callback synchronized, preventing tooltip race conditions when background threads (such as FastJEI workers) build tooltips concurrently.
  • Apotheosis Socketing JEI Extension: Registers SocketingRecipe in JEI's vanilla smithing category (respecting Apotheosis.enableAdventure), links focus slots, and caches immutable example lists across slot renders.
  • CoO × Structurify Overlap Gate: Optional CoreMod disabling only Collections of Optimizations' MixinStructureOverlapCheck when paired with audited Structurify builds (2.0.42 / 2.0.43).

🎯 Fixes vs. Tweaks — Which One Do You Need?

HollowRealm's custom maintenance is split cleanly into two complementary mods with zero overlapping targets:

  • HollowRealm Fixes (hollowrealm_performance_compat) — Code & Mixin layer: fixes crashes, thread-safety races, JEI socketing display, and the optional CoO/Structurify coremod conflict.
  • HollowRealm Tweaks (hollowrealm_tweaks) — In-memory Server Data layer: repairs clam loot condition IDs, restores the shadowed annihilation bottle recipe, and gates optional Scguns affixes when Scguns is absent.

Both mods are designed and verified to run together safely.

📋 Requirements & Compatibility

  • Environment: Minecraft 1.20.1 · Forge [47.4.16, 48) (verified on Forge 47.4.29) · Java 17.
  • Multiplayer / Side: Uses IGNORE_SERVER_VERSION; safe for client or server installations matching your pack setup.
  • Optional Target Mods: All patched mods (Apotheosis 7.4.8, JEI 15.56.0.205, Lodestone 1.20.1-1.6.4.1, ApothicAttributes 1.3.7, L2 Hostility 2.5.19, L2 DamageTracker 0.4.4, CoO 4.6/5.5/6.5, Structurify 2.0.42/2.0.43) are optional and independently gated.
  • Single-JAR Rule: Keep only one JAR with mod ID hollowrealm_performance_compat installed. Remove legacy hr-fixes-*.jar files when upgrading.
