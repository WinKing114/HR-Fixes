# HollowRealm Fixes

**HollowRealm Fixes** is a lightweight compatibility and bug-fix mod made specifically for the **HollowRealm** modpack. Formerly known as **HR Fixes**.

It uses targeted Java and Mixin patches to address mod conflicts, crashes and bugs in the pack, while preserving its intended gameplay. Modpack-specific content and balance changes are handled separately.

**Minecraft 1.20.1 · Forge · Java 17**

Use the version provided for your HollowRealm installation, and keep only one HollowRealm Fixes / HR Fixes JAR installed. See each file's changelog for version-specific changes and compatibility notes.
